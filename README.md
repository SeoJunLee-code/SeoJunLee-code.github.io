# AEVORIN — Independent AI Research & Engineering

Static site (EN at `/`, KO at `/ko/`). Numbers come from `data/research.json`, which `tools/extract.py` generates from source analysis files.
Page text lives in `tools/content.py`; `tools/build.py` renders the pages and subsets the fonts.

```bash
python3 -I tools/extract.py /path/to/Nexus-.github.io     # regenerate data/research.json
FONT_SRC=/path/to/ttf python3 -I tools/build.py            # build pages + fonts (--no-fonts to skip fonts)
python3 -I -m unittest discover -s tests -v                # forbidden-string scan, link check, number-to-data check
python3 -m http.server 8000                                # preview
```

Fonts (OFL): Cormorant Garamond, Inter, Noto Serif KR, Noto Sans KR. Source TTFs are not stored here (`tools/fontsrc/` is git-ignored).
`build.py` subsets each family whose sources are present (`tools/fontsrc/<Prefix>_<weight>.ttf`) and keeps the current woff2 + `@font-face`
for families whose sources are absent. Korean sources: static instances of Google Fonts `NotoSansKR[wght].ttf` (400, 500) and
`NotoSerifKR[wght].ttf` (500), made with `fontTools.varLib.instancer`. The Latin sources are not available, so non-Hangul visible text may use
only the characters in `tools/font_chars.txt`; Hangul may use anything, and a test checks every syllable is in the KR woff2 files.
Without any sources, build with `--no-fonts`.
`sitemap.xml` and `robots.txt` are generated by `build.py`; do not edit them by hand.
Hand-verified figures (Phase 2b, Study 4, LLM test counts) are marked `verified` in the data file.
