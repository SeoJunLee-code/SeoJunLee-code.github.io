AEVORIN

Independent AI Research & Engineering. Aevorin is a coined name, not an existing word. It joins Aevo, inspired by aevum (an age, a long span of time), with Orin, which suggests origin. The meaning we take from it: explore a new era of intelligence, and build possibilities beyond what already exists.

Philosophy

Discover
We look for what is not yet known.
Construct
We build the thing itself, not only a description of it.
Advance
We keep what holds up and move it forward; we record what does not.

How we work with AI

Human-led research direction
The author chooses the questions and what is published.
AI-assisted implementation
Code, analysis scripts, documentation and this site were written with AI assistance. Each project page says what is known about its AI use; where there is no itemised record, it says so.
Checked against sources
Numbers on this site are generated from source files by script and checked by tests. Some were checked by hand against original reports; each page says which. None has had independent peer review.

Evidence labels

Measured a result produced and read from files; Reported stated in a document, not re-run; Judgment the author's interpretation; Unverified not tested.
