컨텍스트 압축 — 컨텍스트 압축은 Claude Code 사용량을 줄일까?

혼합 결과

대화 컨텍스트를 압축하면 작업 품질을 해치지 않고 Claude Code 구독 사용량을 줄일 수 있을까?

Sonnet 5.5에서는 절감 효과가 없었고(전체 기록 대비 0.96~1.52배), Haiku 5.5에서는 100K 토큰을 넘는 경우 0.33배였습니다. 호출마다 붙는 고정 컨텍스트를 줄이는 편이 효과가 더 컸습니다.

알고리즘 혁신 — 캐시 라인 하나만 읽는 근사 멤버십 필터

혼합 결과

블록 부하에 따라 지문 길이를 바꾸고 캐시 라인 하나만 읽는 삽입 전용 필터는, 같은 메모리에서 실용적인 비용으로 blocked Bloom과 Prefix filter를 이길 수 있을까?

같은 메모리에서 오탐률은 blocked Bloom의 0.117~0.695배였지만 속도는 더 느렸고, 핵심 메커니즘은 이미 TinySet으로 발표되어 있었습니다.

AI 책임 — AI 에이전트에 대한 구조적 책임

가설 반증

의식이나 도덕적 지위를 전제하지 않고도, AI 에이전트와 제도적 구조를 결합하면 책임의 기능을 수행할 수 있을까?

처음 세운 형태의 논지는 기각됐습니다. 남은 것은 에이전트가 없어도 작동하는 것들, 곧 배포자의 책임과 기록입니다.

AI 망각과 복습 — 정해진 예산 안에서 무엇을 지우고 무엇을 복습할지 함께 정하는 모델

혼합 결과

저장·연산 예산이 고정되어 있을 때, 항목마다 필요도를 추정하는 모델 하나로 삭제와 복습을 함께 정하면 같은 예산의 단순 기준선보다 나을까?

연구 A는 주 가설을 지지했고(실제 대화에서 LRU보다 +19.45%p), 연구 B는 실행하지 않았습니다.

AI 창의성 — Doxa Negation Search (가정 부정 탐색)

가설 반증

여러 아이디어가 암묵적으로 공유하는 가정을 찾아내 뒤집으면, AI가 창의적인 아이디어를 만들고 발전시킬 수 있을까?

사전등록한 핵심 가설은 기각됐고, 흔히 쓰는 비판·개선 루프는 핵심 유지도를 5.00에서 1.88로 떨어뜨렸습니다.

KORE — Knowledge Orchestration & Retrieval Engine

프로토타입 · 미검증

아직 결과가 없으며, 검증된 것도 없습니다.

H1 — 다수결 역효과

가설 반증

모델이 가끔 정답을 내는 문제에서 다수결은 절반 넘게 틀릴까?

네 조건 모두에서 가설이 반증됐습니다. 역효과 비율은 14%~21%입니다.

Paper 5 — 내부 신호로 성공 예측

진행 중

에이전트의 초기 내부 신호로 성공 여부를 예측할 수 있을까, 아니면 그 신호는 학습 정도만 반영할까?

초기 AUROC 0.820은 대부분 학습 설정 k로 설명되고, 더 엄격한 후속 실험에서는 신호가 검출되지 않았습니다(0.548).

LLM Internal Computing — LLM 안의 결정론적 컴퓨터 검증

부분 재현

LLM 안에 결정론적 컴퓨터를 넣은 두 업스트림 프로젝트의 단위 테스트는 고정한 커밋에서 통과할까?

첫 실행에서는 테스트 282개 중 246개, 562개 중 479개가 통과했습니다. 성능에 대한 주장은 하지 않습니다.

연구 4 — 월드 모델 연구

탐색적 · 시드 3개

원본 보고서는 두 환경(maze, empty)에서 학습 3,000·12,000·24,000스텝 시점에 막힘 예측, 위치 프로브, 인과 개입의 세 가지를 측정합니다.

maze 3000스텝에서 위치 프로브는 0.286, 학습하지 않은 네트워크는 0.238입니다(학습하지 않은 네트워크로 설명되는 몫 83%).
