KORE

Knowledge Orchestration & Retrieval Engine

Prototype · UnvalidatedAI-assisted implementationNo independent review
Research questionCan a retrieval layer pick the knowledge that actually helps a language model answer, and does it beat plain RAG under identical conditions?
Nothing has been validated yet. The repository's own README says so. The sample data (15 documents, 9 questions) only checks that the pipeline runs; it supports no conclusion about KORE versus plain RAG.

Question

Language models answer better with the right outside knowledge, but retrieval often returns text that looks relevant without helping. KORE is a prototype that tries to select the knowledge that actually helps, and compares it with plain RAG under identical conditions.

What exists

  • Experiment skeleton and a resumable experiment runner
  • BM25 retrieval, a weighted selector, and evaluation code with bootstrap intervals
  • A generator that uses free open models, and tools for labelling how much each document contributed
  • Data-checking tools and tests

What is not done

  • The hypotheses (H1–H3), the KORE-versus-RAG comparison and the originality claim are all untested Unverified
  • No real evaluation set is approved: a 20-question draft written with AI help is waiting for human approval
  • Large-scale runs on GPU were not done in the environment where the code was written
