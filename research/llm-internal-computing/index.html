LLM Internal Computing

Verifying a deterministic computer inside an LLM

Reproduction · PartialAI-assisted implementationNo independent reviewRepository: not public yet
Research questionDo the unit tests of two upstream projects that embed a deterministic computer in an LLM pass at pinned commits?
Reproduction only. This work runs the unit tests of two upstream projects at pinned commits. It reports pass and fail counts and causes. It contains no performance figures, and the upstream projects' claims about circuits, riscv-tests and benchmarks were not reproduced.

Question

Two open projects, QwenPU and Qwenputer, embed a deterministic computer inside a language model. Before building on them, do their own unit tests pass at a fixed version?

Attribution

The upstream projects are by divagr18 (qwenpu at commit 5af1fc0, qwenputer at commit bec1a0c). This repository does not copy their code; it points to the commits. The commits are the heads at the time of cloning, not versions chosen by the upstream authors.

Failures and errors fall into four causes: a test that no longer matches the upstream code, missing input files, a process killed for lack of memory, and the time limit. This does not show that the upstream implementation is right or wrong.

Reruns Measured

  • On Colab (13 GB RAM), the 6 memory-heavy tests that the container could not finish all passed
  • One test file that had been cut off at the time limit then completed: 113 of 113 passed
  • Another stopped again at a longer limit: 3 of 6 passed, stopped by a 3000 s limit. Whether a longer limit changes this is Unverified

Limitations

  • Unit tests only; no performance numbers and no claim that the upstream design works as advertised
  • The first-run table is a record of the container runs and was not rewritten after the reruns
  • Some failures may come from tests left behind by upstream changes; this is a judgment, not a verified cause

Verification and AI use

Counts were checked against the project's test report. AI-assisted implementation. No independent review. Tests were run in a container and on Colab.
