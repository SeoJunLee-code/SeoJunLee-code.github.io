Paper 5

Predicting success via internal signals

In ProgressAI-assisted implementationNo independent review
Research questionCan an agent's early internal signal predict whether it will succeed, or does it only reflect how well it was trained?
In progress. The pre-registered next step (1j) has not been run. So far the data do not support reading the signal as “confidence”.

Question

A reinforcement-learning agent scores every action with a Q value. Its maximum, maxQ, roughly says how good the agent thinks the situation is. Can the maxQ over the first five steps predict whether the agent later reaches a key? And is that signal really “confidence”, or just how well the agent was trained (the training setting k)?

Method

A start close to the key makes success easy, so the comparison is fair only within the same run and the same distance. Stratified AUROC compares successes and failures only inside such strata (0.5 = chance, 1 = perfect). Only step 1f was pre-registered; the others are exploratory.

Result 1 — the early signal and its decomposition Measured

In the decomposition (step 1i), maxQ over the first steps reaches AUROC 0.820 for the deterministic agent. But k alone gives 0.788, and after removing what k explains, only 0.597 [0.503, 0.688] remains. Most of the signal is the training setting.

Result 2 — a different run set Measured

On another set of runs (steps 1g/1h, 120 runs, 752 episodes) the total is 0.680 [0.596, 0.762]; after removing k it is 0.511 [0.442, 0.585], which includes 0.5. (Step 1g reports the same number under the name “layout×distance”; the two intervals differ slightly because they were computed separately.)

Result 3 — a stricter follow-up (Phase 2b) Measured

With comparison restricted to the same run and the same distance after four steps, the AUROC is 0.548 [0.486, 0.605] (interval width 0.120) on 3,478 samples, 2,639 of them successes, 8,931 comparable pairs in 116 strata. The pre-set verdict: no signal detected (and the interval is narrow enough to say so).

  • A weaker control that matches only the starting distance gives 0.794 [0.756, 0.831]; it was not used for the verdict
  • Pooled with the earlier main experiment: 0.544 [0.476, 0.598] (reference only; the designs differ slightly)

What this means Judgment

The early AUROC of about 0.8 is mostly the training setting. Under stricter matching, maxQ is near chance. The “confidence” reading is not supported so far; the pre-registered step 1j, which excludes the extreme k=2 setting, is the planned test and has not been run.

Limitations

  • Only step 1f was pre-registered; its original text is not kept (only its hash), so it cannot be compared with the stated hypothesis
  • Phase 2b was designed after the earlier main experiment's results were seen. Its pre-registration was locked before the new seeds ran, and the verdict follows one pre-set line
  • The environment and agent are re-implementations; results are about this environment and do not generalise to other settings
  • Step 1c scanned many signals and conditions at once, with no multiple-comparison correction on record
  • Hypotheses H-B1 and H-B2 were not re-tested in Phase 2b
  • Code for steps 1b–1h lives only in notebooks, so its hashes are not available

Verification and AI use

Steps 1g–1i figures were generated from the project's analysis files by script and checked by tests. The Phase 2b figures were checked by hand against the original report and result files. AI-assisted implementation. No independent review.
